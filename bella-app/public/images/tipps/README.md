# Tipps Bilder Strategie

## Ordnerstruktur

Jeder Tipp-Artikel benötigt ein Hauptbild im Format 1200x630px (16:9) für optimale SEO und Social-Media-Darstellung.

## Benennungskonvention

```
[category]-[tip-slug].jpg
```

Beispiele:
- `ernaehrung-fleisch-an-erster-stelle.jpg`
- `ernaehrung-offene-deklaration.jpg`
- `ernaehrung-fleischanteil.jpg`

## Bild-Anforderungen

### Hauptbild (Hero Image)
- **Größe:** 1200x630px (16:9)
- **Format:** JPG oder WebP
- **Dateigröße:** < 200KB (optimiert)
- **Alt-Text:** Beschreibend, SEO-optimiert, enthält Hauptkeyword

### Bild-Inhalte
- Hunde beim Fressen
- Hundefutter-Produkte
- Deklarationen/Etiketten
- Hunde in verschiedenen Lebensphasen
- Gesunde Hunde mit glänzendem Fell

## Platzhalter-Strategie

Bis echte Bilder verfügbar sind, können folgende Optionen verwendet werden:

### Option 1: Unsplash/Stock-Fotos
- Kostenlose hochwertige Bilder von Unsplash
- Relevante Keywords: dog food, dog eating, pet nutrition

### Option 2: SVG-Platzhalter
- Generische SVG-Platzhalter mit Kategorie-spezifischen Farben
- Enthält Tipp-Titel als Text

### Option 3: Farbverlauf-Platzhalter
- CSS-basierte Farbverläufe mit Kategorie-Akzentfarbe
- Enthält Icon und Titel

## Bild-Optimierung

Für die Produktion sollten Bilder optimiert werden:
- WebP-Format für moderne Browser
- Lazy Loading für Performance
- Responsive Bilder mit srcset
- CDN-Integration für schnelle Ladezeiten

## SEO-Best Practices

- Dateiname enthält Keywords
- Alt-Text ist beschreibend (nicht "image1.jpg")
- Title-Attribut bei Bedarf
- Strukturierte Daten mit ImageObject
