# SEO Operating System

## Objective
Dominate organic search in Germany for: Handyvertrag, Handy mit Vertrag,
Smartphone mit Vertrag, iPhone mit Vertrag, Samsung mit Vertrag,
Tarifvergleich, Mobilfunkberatung.

Every SEO decision must increase: Topical Authority, Search Visibility,
User Satisfaction, Revenue.

## Rule 1
SEO is a product feature. Every page must solve a search problem better than competitors.

## Search Intent First
One page = one primary intent (Informational / Commercial / Transactional / Navigational).

## Topical Authority Model
Build topic clusters. Every page belongs to a cluster. No isolated content.
Handyvertrag → Telekom / Vodafone / O2 / 5G / Unlimited / Studenten / Junge Leute / Prepaid / eSIM / ohne Handy.

## Entity SEO
Optimize for entities, not keywords. Build semantic relationships:
iPhone 16 ↔ Telekom ↔ Unlimited ↔ eSIM.

## Internal Linking
Every page: min 3 incoming + 3 outgoing links. No orphan pages.

## Content Quality
Original analysis, comparison, recommendation, decision support, examples.
If content can rank unchanged on 100 sites: rewrite it.

## EEAT
Clear author, update date, data sources, methodology, comparison criteria.

## Programmatic SEO
Allowed: city / device / provider / use-case pages.
Each MUST have unique intro, recommendations, internal links, schema, FAQs.
No thin content.

## Device SEO Strategy
For every major phone: Brand Page, Device Page, Provider Combination Pages.
/iphone-16-mit-vertrag, /iphone-16-pro-telekom, etc. Full topic ownership.

## Long Tail Strategy
Capture intent variations: "bestes iphone mit vertrag", "iphone für studenten",
"iphone ohne anzahlung", "iphone unter 50 euro monatlich".

## Schema
FAQPage, Product, Review, ItemList, BreadcrumbList, Organization, WebSite.
Structured data must match visible content. No spam schema.

## Featured Snippets
Definitions, numbered lists, comparison tables, direct answers. Target position zero.

## Content Freshness
Review prices, providers, devices, tariffs periodically. Freshness is ranking leverage.

## Success Metrics
impressions, clicks, CTR, rankings, conversions, revenue, pages indexed,
internal link coverage. Ignore vanity metrics.

## Golden Rule
Do not create pages. Create the best answer on the internet.
If a page cannot become Top 3: do not publish it.
